# ProjectBeta - Sanskriti School Tech Club

**Where Innovation Meets Passion**

A modern, multi-page website for ProjectBeta, Sanskriti School's premier technology club. Built with cutting-edge web technologies to showcase the club's mission, members, departments, and events.

## 🚀 Tech Stack

- **Next.js 16** - React framework with App Router
- **TypeScript** - Type-safe development
- **TailwindCSS 3** - Utility-first CSS framework
- **React 19** - UI components

## ✨ Features

- **Responsive Design** - Mobile-first approach ensuring perfect display on all devices
- **Modern UI/UX** - Glassmorphism effects, gradient text, and smooth animations
- **6 Main Pages**:
  - Landing Page - Hero section with stats and mission
  - Register - Interactive registration form for ProjectBeta 9.0
  - Members - Executive board and department leads showcase
  - Departments - 6 tech departments with detailed descriptions
  - Events - Upcoming and past events calendar
  - Contact - Contact form with FAQ section
- **Reusable Components** - Button, Card, Input, TextArea, Badge
- **Smooth Animations** - Fade-in, slide-up, float effects
- **Professional Navigation** - Fixed navbar with mobile hamburger menu
- **Footer** - Quick links and social media integration

## 🎨 Design Philosophy

- **Navy Blue Theme** - Professional dark background (#0a1628)
- **White Accents** - Clean, high-contrast text
- **Glassmorphism** - Modern frosted glass effects
- **Gradient Elements** - Subtle gradients for visual depth
- **Micro-interactions** - Hover effects and button animations

## 📦 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/gaurangkhera/projectbeta.git
cd projectbeta
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
npm start
```

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
